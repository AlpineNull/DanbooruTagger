Danbooru Tagger v0.7.3-dev
PixAI Tagger v1.0 — model unchanged

FEATURES
- LOCAL mode (default): local tag metadata checks using JSON and SQLite;
  no automatic tag-related Danbooru API calls during ordinary analysis.
- HYBRID mode: optional live API checks for missing or stale metadata.
- Manual metadata refresh via the official API.
- Tag existence, alias, deprecated flag, and implication checks.
- Conservative conflict resolution for disagreeing JSON/SQLite entries.
- Cloudflare challenge detection and backoff; local fallback.
- Character suggestions, context warnings, and raw confidence exports.
- Configurable confidence thresholds, blacklist, and VRAM idle unload.

v0.7.3 DEVELOPMENT CHANGES
- Editable HIGH/MEDIUM/LOWEST outputs and optional local feedback records.
- Fix translation_request advice for bilingual_text.
- Clarify that SQLite hit counts represent local metadata records, not SQL queries.
- Preserve PixAI Tagger v1.0 model weights and existing user caches/settings.

v0.7.2 CHANGES
- Status messages wrap correctly and no longer overlap the progress bar.
- Windows SQLite test connections are closed before temp-file cleanup.
- Cleaned up mocked HTTP error resources in the test suite.

First-install dependencies and model are downloaded separately.
